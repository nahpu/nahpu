Crie um pacote de dados relacional para intercâmbio, validação ou preservação.

## Etapas

1. Abra `Bundle records` e escolha `Darwin Core Data Package` ou `NAHPU Data Package`.
2. Use Darwin Core para tabelas de biodiversidade baseadas em padrões; use NAHPU quando forem necessários metadados do projeto, configurações do usuário e relações do NAHPU.
3. Selecione TAR.GZ ou ZIP quando o pacote escolhido aceitar ambos.
4. Gere o pacote e revise avisos de mídia ausente ou relações inválidas.
5. Inspecione descriptor, tabelas de dados e manifest antes de compartilhar ou arquivar.

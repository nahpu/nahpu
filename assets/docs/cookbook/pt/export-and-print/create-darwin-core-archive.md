Empacote registros de biodiversidade em tabelas de texto Darwin Core para fluxos de dados compatíveis.

## Etapas

1. Abra o menu do projeto e selecione `Bundle records`.
2. Escolha `Darwin Core Archive`.
3. Selecione a abrangência de registros e revise os campos Darwin Core mapeados.
4. Escolha as opções do arquivo e gere o pacote.
5. Revise avisos, inspecione `meta.xml` e as tabelas de saída e valide o arquivo antes da publicação.

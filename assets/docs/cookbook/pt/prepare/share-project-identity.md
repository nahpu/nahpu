Crie outra cópia do projeto com o mesmo UUID sem transferir registros.

## Etapas

1. No dispositivo de origem, abra o menu de ações do projeto.
2. Escolha `Show QR` para um dispositivo móvel próximo ou `Export info` para gerar um arquivo JSON.
3. No dispositivo receptor, inicie `New project`.
4. Escolha `Scan project QR` ou `Import project-info JSON`.
5. Revise a identidade importada e crie o projeto.

> **Cuidado:** As informações do projeto contêm apenas identidade e metadados; use a transferência de projeto para mover registros ou mídia.

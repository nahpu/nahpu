Adicione um nome taxonômico ao registro do projeto para a identificação de espécimes.

## Etapas

1. Abra o painel do projeto e localize `Taxon Registry`.
2. Selecione `Add taxon`.
3. Informe classe, ordem, família, gênero e epíteto específico.
4. Adicione autoria, nome vernacular, status de conservação ou notas quando disponíveis.
5. Salve e confirme que o táxon aparece no registro do projeto.

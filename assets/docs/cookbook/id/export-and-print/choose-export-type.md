Pilih backup, transfer, structured export, atau publishing bundle sesuai penggunaan berikutnya.

## Langkah

1. Untuk pemulihan bencana, pilih `Backup database`.
2. Untuk menggabungkan perangkat NAHPU, pilih `Export project`; gunakan JSON.GZ tanpa media atau ZIP/TAR.GZ dengan media.
3. Untuk spreadsheet atau analisis, pilih `Export records`.
4. Untuk berbagi berbasis standar, pilih `Bundle records` lalu pilih Darwin Core Archive, Darwin Core Data Package, atau NAHPU Data Package.
5. Untuk label atau laporan, pilih `Export documents`.

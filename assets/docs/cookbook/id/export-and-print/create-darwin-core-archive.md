Paketkan biodiversity record dalam tabel teks Darwin Core untuk alur data yang kompatibel.

## Langkah

1. Buka drawer proyek lalu pilih `Bundle records`.
2. Pilih `Darwin Core Archive`.
3. Pilih cakupan record dan tinjau field Darwin Core yang dipetakan.
4. Pilih opsi arsip lalu buat bundle.
5. Tinjau peringatan, periksa `meta.xml` dan tabel keluaran, lalu validasi arsip sebelum publikasi.

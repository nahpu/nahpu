Susun document template pada halaman dan verifikasi PDF akhir.

## Langkah

1. Buka `Settings` > `Documents` > `Print layouts` lalu buat atau duplikasi layout.
2. Atur ukuran halaman, orientasi, margin, dan padding.
3. Tambahkan template block lalu atur copies, rows, columns, ordering, dan pagination.
4. Buka `Export documents`, pilih layout, lalu pilih record yang representatif.
5. Buat pratinjau dan periksa teks panjang, halaman pertama dan terakhir, alignment, serta kedua sisi bila berlaku.
6. Isi nama berkas lalu ekspor PDF.

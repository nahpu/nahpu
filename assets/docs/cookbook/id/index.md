Langkah singkat dan terarah untuk alur kerja lapangan dan data yang umum di NAHPU.

Baru menggunakan NAHPU? Mulailah dengan [Hari Pertama](https://nahpu.app/id/day-one/) di situs web untuk mempelajari konsep utama dan berlatih dengan proyek contoh. Jika ekspor berhenti dengan galat (error), lihat [Periksa dan perbaiki basis data](https://nahpu.app/id/how-to-recipes/protect-and-collaborate/check-and-repair-database/) untuk menemukan dan memperbaiki rekaman yang bermasalah.

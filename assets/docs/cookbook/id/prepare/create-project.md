Buat identitas proyek dan pengaturan katalog lokal yang digunakan record baru.

## Langkah

1. Pada layar utama, pilih `+`, lalu `New project`.
2. Pilih `Create new project`, lalu isi informasi proyek dan zona waktu IANA.
3. Pilih format taxon utama untuk formulir specimen baru pada perangkat ini.
4. Pilih Field ID berbasis personel atau proyek dan lengkapi data Cataloger yang diminta.
5. Tinjau ringkasan lalu pilih `Create project`.

Catat satu sampling effort yang terdefinisi pada site dan waktu tertentu.

## Langkah

1. Buka halaman Events lalu pilih `+`.
2. Pilih Site ID lalu isi tanggal dan waktu mulai serta selesai.
3. Tinjau Event ID yang dibuat dan tambahkan akhiran hanya bila diperlukan agar unik.
4. Lengkapi bagian activity, effort, personnel, weather, dan astronomy.
5. Simpan event sebelum menghubungkan specimen record.

> **Kiat:** Buat event terpisah bila site, rentang waktu, sampling protocol, effort, atau tim berubah secara berarti.

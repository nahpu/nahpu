Empaquete registros de biodiversidad en tablas de texto Darwin Core para flujos de datos compatibles.

## Pasos

1. Abra el menú del proyecto y seleccione `Bundle records`.
2. Elija `Darwin Core Archive`.
3. Seleccione el alcance de registros y revise los campos Darwin Core asignados.
4. Elija las opciones del archivo y genere el paquete.
5. Revise advertencias, inspeccione `meta.xml` y las tablas de salida y valide el archivo antes de publicarlo.

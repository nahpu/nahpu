Guarde una configuración reutilizable de selección de registros, asignación de campos y encabezados.

## Pasos

1. Abra `Settings` > `Tabular Data`.
2. Cree un preset y asígnele un nombre descriptivo.
3. Elija el tipo de registro, alcance taxonómico y modo de campos.
4. Añada y ordene campos y configure asignaciones estándar o encabezados personalizados.
5. Guarde el preset y pruébelo en `Export records` con datos representativos.

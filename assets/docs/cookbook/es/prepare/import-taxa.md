Registre varios taxones desde una hoja de cálculo o un archivo delimitado.

## Pasos

1. Prepare datos `.xlsx`, `.csv` o `.tsv` con columnas de clase, orden, familia, género y epíteto.
2. Abra `Taxon Registry` y seleccione `Import from file`.
3. Elija el archivo y revise la asignación de columnas detectada.
4. Corrija las columnas no asignadas o use la opción avanzada del analizador si no se detectó el delimitador.
5. Importe y revise los taxones registrados antes de registrar especímenes.

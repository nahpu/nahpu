Cree un registro reutilizable del lugar para eventos de recolección.

## Pasos

1. Abra la página Sites y seleccione `+` o `Create site`.
2. Introduzca un Site ID único y estable y seleccione la persona responsable y el tipo de sitio.
3. Registre país, estado/provincia, condado, municipio, localidad precisa y observaciones según corresponda.
4. Describa el tipo, la condición y las características observadas del hábitat.
5. Use `Duplicate site` para sitios similares o `Copy from project` para reutilizar información de otro proyecto y después asigne un Site ID nuevo.

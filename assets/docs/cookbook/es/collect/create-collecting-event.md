Registre un esfuerzo de muestreo definido en un sitio y período.

## Pasos

1. Abra la página Events y seleccione `+`.
2. Elija el Site ID e introduzca fechas y horas de inicio y fin.
3. Revise el Event ID generado y añada un sufijo solo cuando sea necesario para garantizar que sea único.
4. Complete las secciones de actividad, esfuerzo, personal, clima y astronomía.
5. Guarde el evento antes de vincular registros de especímenes.

> **Consejo:** Cree otro evento cuando cambien de forma relevante el sitio, el período, el sampling protocol, el esfuerzo o el equipo participante.

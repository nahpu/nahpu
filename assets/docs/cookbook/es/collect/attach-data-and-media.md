Conecte archivos de apoyo, enlaces, imágenes, audio y video con un registro.

## Pasos

1. Abra el registro y elija `Associated Data` para enlaces o archivos que no sean medios.
2. Elija `Media` para imágenes, audio o video compatibles.
3. Importe un archivo existente o use las acciones disponibles de cámara, video o grabación de audio.
4. Añada un título claro, tipo de recurso, creador o fotógrafo y notas.
5. Abra el adjunto una vez para confirmar que el archivo administrado o el enlace funcione.

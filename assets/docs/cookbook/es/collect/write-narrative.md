Registre contexto de campo que no corresponde a un campo estructurado de sitio, evento o espécimen.

## Pasos

1. Abra Narratives y seleccione `+`.
2. Introduzca fecha, hora, autor y Site ID relacionado.
3. Escriba observaciones, decisiones y contexto concisos con compatibilidad Markdown.
4. Adjunte medios relevantes cuando aporten evidencia o contexto.
5. Previsualice la entrada y guárdela.

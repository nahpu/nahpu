Sustituya los datos activos de la instalación por una copia verificada de NAHPU.

## Pasos

1. Cree una copia actual de la base de datos activa.
2. Abra `Settings` > `Database` y elija `Replace database`.
3. Seleccione la base SQLite o el archivo de copia de NAHPU compatible.
4. Revise la advertencia y confirme solo después de comprobar el archivo de origen.
5. Reinicie o vuelva a abrir NAHPU si se solicita y verifique proyectos, recuentos y archivos administrados.

> **Precaución:** La sustitución sobrescribe la base de datos activa; no combina proyectos.

Combine records from another copy of the same project through guided conflict review.

## Steps

1. Back up the receiving database.
2. Open the receiving project and select `Merge project`.
3. Choose a project JSON.GZ, ZIP, TAR.GZ, or compatible NAHPU Data Package.
4. Review project information, personnel, taxonomy, sites, events, specimens, and narratives in order.
5. For each conflict, choose `Keep current`, `Use imported`, `Import as new`, or `Skip`.
6. Review the final summary, run the merge, and verify counts and media afterward.

> **Caution:** Use `Force merge` only when different UUIDs truly refer to the same field project and the mismatch has been investigated.

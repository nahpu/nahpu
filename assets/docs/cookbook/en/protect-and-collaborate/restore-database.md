Replace the active installation data with a verified NAHPU backup.

## Steps

1. Create a current backup of the active database.
2. Open `Settings` > `Database` and choose `Replace database`.
3. Select the SQLite database or supported NAHPU backup archive.
4. Review the warning and confirm only after checking the source file.
5. Restart or reopen NAHPU if requested, then verify projects, counts, and managed files.

> **Caution:** Replacement overwrites the active database; it does not merge projects.

Create another project copy with the same UUID without transferring records.

## Steps

1. On the source device, open the project action menu.
2. Choose `Show QR` for a nearby mobile device or `Export info` for a JSON file.
3. On the receiving device, start `New project`.
4. Choose `Scan project QR` or `Import project-info JSON`.
5. Review the imported identity and create the project.

> **Caution:** Project information contains identity and metadata only; use project transfer to move records or media.

Arrange document templates on pages and verify the final PDF.

## Steps

1. Open `Settings` > `Documents` > `Print layouts` and create or duplicate a layout.
2. Set page size, orientation, margins, and padding.
3. Add template blocks and configure copies, rows, columns, ordering, and pagination.
4. Open `Export documents`, choose the layout, and select representative records.
5. Generate a preview and check long text, first and last pages, alignment, and both sides when applicable.
6. Enter the filename and export the PDF.

Uma predefinição de exportação tabular salva uma definição reutilizável: o tipo de registro, o grupo taxonômico do espécime, os campos selecionados e sua ordem, o formato do cabeçalho gerado e como os valores repetidos são escritos. O formato de saída, o nome do arquivo e o destino são escolhidos durante a exportação.

`Generated header format` determina como os cabeçalhos são nomeados: `table::fieldName`, `fieldName`, Darwin Core ou o namespace do NAHPU. Os valores repetidos podem ser escritos em uma coluna com um separador ou distribuídos em colunas indexadas como `field_1` e `field_2`.

Exceto pelas alterações de nome e descrição, as personalizações da predefinição são salvas conforme você as faz.

O NAHPU oferece predefinições padrão para ajudar você a começar. Use `Edit fields` para personalizá-las.

A geografia descreve a hierarquia administrativa do local, do país até a localidade precisa. Observações é um campo aberto para o contexto que não cabe em nenhum dos campos nomeados. Você pode configurar quais campos geográficos aparecem em `Settings` > `Sites` > `Geography fields`.

As localidades são armazenadas uma vez e compartilhadas entre locais de diferentes projetos, portanto reutilizar uma localidade salva evita criar locais duplicados. Depois de criar um local, use o campo de busca `Find existing locality` na parte superior do painel de geografia para economizar tempo e manter nomes de localidade consistentes.

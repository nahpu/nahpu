Um projeto agrupa os locais, eventos de coleta, espécimes, pessoal, táxons, narrativas e arquivos de apoio de um mesmo trabalho. Use `Edit` para atualizar as informações do projeto. Defina o fuso horário do projeto para descrever os horários locais registrados. Alterá-lo não converte os valores de data e hora existentes. O fuso horário também é armazenado caso aplicativos de terceiros precisem dele.

O UUID do projeto identifica o projeto entre dispositivos. `Export info` e `Show QR` compartilham sua identidade e metadados, sem registros ou mídia.

Para um backup diário em campo, use `Export project`. ZIP e TAR.GZ incluem a mídia disponível; o formato leve JSON.GZ contém registros sem mídia.

Os dados ambientais registram as condições deste evento. Em `Settings` > `Events`, escolha quais campos integrados exibir no painel. Ocultar um campo não exclui seus valores armazenados nem os remove das exportações.

Registre as medições nas unidades exibidas: temperatura em °C, umidade em porcentagem e precipitação em milímetros. A cobertura de nuvens usa códigos de 0 a 8 para oitavos do céu coberto, ou 9 para um céu obscurecido. Deixe vazios os valores não medidos; zero é uma medição.

Um evento duplicado começa com os dados ambientais vazios.

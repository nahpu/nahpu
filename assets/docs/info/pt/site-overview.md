---
title: "Identidade do site"
sidebar:
  order: 0
---

Um site é o registro reutilizável de lugar no NAHPU e corresponde às informações de localização usadas por eventos de coleta. Dê a cada site um Site ID estável e único no projeto e use uma convenção comum em todos os dispositivos colaboradores.

Registre a pessoa responsável e o tipo de site quando forem úteis. Use `Duplicate site` para copiar informações descritivas, mantendo vazios o novo Site ID e as coordenadas. Use `Copy from project` somente quando um site de outro projeto tiver informações que devam ser reutilizadas; verifique todos os valores copiados antes da coleta.

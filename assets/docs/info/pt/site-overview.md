Um local é o registro de lugar reutilizável do NAHPU. Os eventos de coleta obtêm sua localização de um local, então dê a cada local um Site ID estável e único no projeto, e use uma única convenção de nomes entre os dispositivos que colaboram.

Registre a pessoa responsável, o tipo de local e as datas de início e fim do trabalho neste local. Um projeto pode conter muitos locais, cada um com suas próprias datas. Os eventos de coleta continuam registrando cada visita. Use `Duplicate site` para copiar as informações descritivas deixando vazios o novo Site ID e as coordenadas. Use `Copy from project ...` apenas quando um local de outro projeto descrever um lugar que deva ser reaproveitado. Verifique cada valor copiado antes de iniciar a coleta.

Um local descreve um lugar; um evento descreve o trabalho nesse lugar. Reutilize o local nas visitas seguintes e crie eventos adequados a cada período de amostragem.

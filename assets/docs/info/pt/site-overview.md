---
title: "Identidade do local"
sidebar:
  order: 0
---

Um local é o registro reutilizável de lugar do NAHPU e corresponde às informações de localização usadas pelos eventos de coleta. Dê a cada local um Site ID estável e único no projeto, e use uma mesma convenção de nomes em todos os dispositivos colaboradores.

Registre a pessoa responsável e o tipo de local quando forem úteis. Use `Duplicate site` para copiar as informações descritivas, deixando vazios o novo Site ID e as coordenadas. Use `Copy from project` apenas quando um local existente em outro projeto representar informações que devam ser reutilizadas; verifique todos os valores copiados antes de começar a coleta.

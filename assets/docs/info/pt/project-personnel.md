O pessoal inclui todas as pessoas que participam do projeto. Cada pessoa é armazenada uma vez no banco de dados e pode ser atribuída a vários projetos. Uma pessoa precisa ser adicionada ao projeto antes de ser adicionada a um registro de local, evento ou espécime. Remover uma pessoa deste painel remove sua atribuição ao projeto; a exclusão permanente do banco de dados é gerenciada em `Settings` > `Personnel`.

Funções do NAHPU:

- **Cataloger:** registra dados de espécimes e pode fornecer iniciais e um número de campo pessoal para os Field IDs.
- **Determiner only:** identifica espécimes, mas não os cataloga nem prepara.
- **Preparator only:** prepara espécimes, mas não os cataloga (por exemplo, não tem um número de campo pessoal nem registra dados de espécimes).
- **None:** participa do trabalho de campo sem uma função de cuidado com o espécime.

Para atribuir um identificador a um espécime, o NAHPU aceita iniciais + um número sequencial, ou um prefixo definido pelo projeto + um número sequencial + um sufixo opcional. O NAHPU chama o primeiro de `Field ID` e o segundo de `Project ID`. Configure essa opção em `Settings` > `Specimens` > `Field ID`.

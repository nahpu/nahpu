El personal incluye a todas las personas que participan en el proyecto. Cada persona se almacena una sola vez en la base de datos y puede asignarse a varios proyectos. Una persona debe añadirse al proyecto antes de poder agregarse a un registro de sitio, evento o espécimen. Eliminar a una persona de este panel elimina su asignación al proyecto; la eliminación permanente de la base de datos se administra en `Settings` > `Personnel`.

Roles de NAHPU:

- **Cataloger:** registra datos de los especímenes y puede aportar iniciales y un número de campo personal para los Field IDs.
- **Determiner only:** identifica especímenes, pero no los cataloga ni prepara.
- **Preparator only:** prepara especímenes, pero no los cataloga (p. ej., no tiene un número de campo personal ni registra datos de especímenes).
- **None:** participa en el trabajo de campo sin un rol de cuidado del espécimen.

Para asignar un identificador a un espécimen, NAHPU ofrece dos opciones: las iniciales del recolector + un número consecutivo, o un prefijo definido por el proyecto + un número consecutivo + un sufijo opcional. El primer formato se denomina `Field ID` y el segundo `Project ID`. Configure esta opción en `Settings` > `Specimens` > `Field ID`.

---
title: "Esfuerzo del evento"
sidebar:
  order: 0
---

Los registros de esfuerzo describen cómo se realizó el muestreo. Agregue cada método por separado y registre la marca o el modelo del equipo pertinente, el número de unidades, el tamaño o las dimensiones, la duración y las notas.

Use las mismas unidades y los mismos nombres controlados de método en todo el proyecto. El método puede alimentar `dwc:samplingProtocol`; la cantidad, la duración, el área u otra magnitud del muestreo alimenta `dwc:samplingEffort`. Indique el contexto suficiente para que otra persona entienda y compare el esfuerzo sin tener que inferir detalles faltantes.

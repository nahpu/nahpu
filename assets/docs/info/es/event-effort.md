---
title: "Esfuerzo de muestreo"
sidebar:
  order: 0
---

Los registros de esfuerzo describen cómo se realizó el muestreo. Añada cada método por separado y registre marca o modelo del equipo, número de unidades, tamaño o dimensiones, duración y notas pertinentes.

Use las mismas unidades y nombres controlados de métodos en todo el proyecto. El método puede sustentar `dwc:samplingProtocol`; cantidad, duración, área u otra magnitud del muestreo sustenta `dwc:samplingEffort`. Proporcione contexto suficiente para comprender y comparar el esfuerzo sin inferir datos ausentes.

Un proyecto agrupa los sitios, eventos de recolecta, especímenes, personal, taxones, narrativas y archivos de apoyo de un mismo trabajo de campo o basado en especímenes. Use `Edit` en la parte inferior del panel Resumen del proyecto para actualizar la información del proyecto.

Establezca la zona horaria del proyecto para describir las horas locales registradas. Cambiar la zona horaria del proyecto no convierte los valores de fecha y hora existentes. La zona horaria se almacena con el proyecto y se incluye en las exportaciones, para que las aplicaciones de terceros puedan interpretar las horas registradas. Las zonas horarias se indican respecto al Tiempo Universal Coordinado (UTC), el estándar de tiempo principal en todo el mundo, desde UTC−12:00 hasta UTC+14:00, cada una con un nombre Continente/Ciudad. Por ejemplo, el horario de verano del este de Estados Unidos aparece como `(UTC-04:00) America/New_York`.

El UUID del proyecto permite identificarlo de manera única entre dispositivos. Para compartir el proyecto con colaboradores, seleccione el código QR del panel Resumen del proyecto para ampliarlo o guardarlo, o seleccione `Export info` en la parte inferior del panel. Los colaboradores escanean el código QR al crear un proyecto nuevo. Las dos opciones permiten compartir el UUID y los metadatos del proyecto, pero no incluyen los registros o archivos multimedia asociados.

Para una copia de seguridad diaria en campo, abra el menú y seleccione `Export project`. Las opciones ZIP y TAR.GZ incluyen todos los registros y los archivos multimedia disponibles; el formato ligero JSON.GZ incluye solo los registros.

Un proyecto agrupa los sitios, eventos de recolecta, especímenes, personal, taxones, narrativas y archivos de apoyo de un mismo trabajo. Use `Edit` para actualizar la información del proyecto. Establezca la zona horaria del proyecto para describir las horas locales registradas. Cambiarla no convierte los valores de fecha y hora existentes. La zona horaria también se almacena por si las aplicaciones de terceros la necesitan.

El UUID del proyecto identifica el proyecto entre dispositivos. `Export info` y `Show QR` comparten su identidad y metadatos, sin registros ni medios.

Para una copia de seguridad diaria en campo, use `Export project`. ZIP y TAR.GZ incluyen los medios disponibles; el formato ligero JSON.GZ contiene registros sin medios.

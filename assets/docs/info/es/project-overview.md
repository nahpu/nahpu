Un proyecto agrupa el personal, los taxones, los sitios, los eventos de recolecta, los registros de especímenes, las narrativas y los medios creados para un mismo trabajo. Use `Edit` para actualizar sus metadatos descriptivos y `Export info` o `Show QR` para compartir solo su identidad.

## UUID del proyecto

NAHPU asigna a cada proyecto nuevo un identificador único universal (UUID). Importar la información del proyecto conserva ese UUID, de modo que los dispositivos colaboradores puedan identificar copias del mismo proyecto. La información del proyecto no incluye registros ni medios; use la transferencia de proyecto cuando estos también deban moverse.

Mantenga breve la descripción del proyecto. Registre el contexto diario detallado en las Narrativas.

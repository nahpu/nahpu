Un proyecto agrupa el personal, los taxones, los sitios, los eventos de recolección, los registros de especímenes, las narrativas y los medios de un mismo trabajo. Use `Edit` para actualizar los metadatos descriptivos y `Export info` o `Show QR` para compartir solo la identidad.

## UUID del proyecto

NAHPU asigna a cada proyecto nuevo un universally unique identifier (UUID). Al importar información se conserva ese UUID para que los dispositivos colaboradores reconozcan copias del mismo proyecto. La información del proyecto no incluye registros ni medios; use la transferencia del proyecto cuando también deba moverlos.

Mantenga la descripción concisa. Registre el contexto diario detallado en Narratives.

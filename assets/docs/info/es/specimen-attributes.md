Los atributos incluyen las mediciones y observaciones biológicas hechas para el espécimen, como el sexo, el estadio de vida, la condición reproductiva, las medidas y otros campos específicos del grupo taxonómico de interés.

Introduzca solo valores observados o documentados y conserve la unidad mostrada. Use `Unknown` o deje un campo vacío según el protocolo del proyecto; no use cero para un valor no medido.

Para peces, elija primero `Individual` para un solo pez o `Lot` para varios individuos almacenados juntos; un lote registra el total de individuos, los rangos de longitud y peso y los individuos medidos.

Use campos personalizados para observaciones adicionales que no cubran los campos integrados de atributos del espécimen. Compruebe su tipo, la convención de unidades y el catálogo aplicable antes de introducir valores.

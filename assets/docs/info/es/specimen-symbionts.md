Un registro de simbiontes documenta un organismo que vive sobre o dentro del espécimen hospedador, ya sea parásito, mutualista, comensal o forético. Use el tipo de interacción para indicar cómo se relaciona con el hospedador y la categoría para indicar dónde vive.

Mantenga la asociación con el hospedador y los identificadores de simbiontes consistentes con las etiquetas de las muestras. Una sección de simbiontes vacía no demuestra que los simbiontes estuvieran ausentes. Use los campos de examen y detección de simbiontes en los atributos del espécimen cuando esa distinción sea relevante.

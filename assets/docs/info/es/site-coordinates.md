Un sitio puede contener varias ubicaciones, como trampas individuales a lo largo de una línea. La opción `Add coordinate` permite ingresar coordenadas manualmente o importarlas de forma masiva en formatos GeoJSON/JSON, KML, Shapefile comprimido en ZIP y GPX.

Para el registro manual, añada un nombre conciso (se usa el nombre del sitio de forma predeterminada), datum, elevación, incertidumbre y unidad GPS cuando se conozcan. Use la incertidumbre de coordenadas indicada por el GPS o estímela usted mismo. También puede usar `Coordinate extent` en el formulario de especímenes para estimar con mayor detalle la ubicación del espécimen respecto a la coordenada registrada.

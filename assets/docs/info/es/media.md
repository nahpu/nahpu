Multimedia almacena imágenes, audio y video compatibles asociados con un registro del proyecto. Use `Add` para importar un archivo o, cuando esté disponible, tomar una foto, grabar un video o grabar audio.

Registre un título claro, el tipo de medio, el autor o fotógrafo, la fecha y las notas, cuando se conozcan. Estos datos describen el recurso multimedia y pueden alimentar metadatos `ac:Media` de Audiovisual Core; no reemplazan los datos de espécimen, evento o localidad. Confirme que el archivo gestionado se abre antes de dejar el campo e incluya los medios en las copias de seguridad o en las transferencias completas de proyecto cuando deban pasar a otro dispositivo.

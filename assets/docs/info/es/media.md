Media almacena imágenes, audio y video compatibles asociados con un registro del proyecto. Use `Add` para importar un archivo o, cuando esté disponible, tomar una foto o video o grabar audio.

Registre un título claro, tipo de medio, creador o fotógrafo, fecha y notas cuando se conozcan. Estos datos describen el recurso y pueden sustentar metadatos Audiovisual Core `ac:Media`; no sustituyen datos de espécimen, evento o ubicación. Confirme que el archivo administrado se abra antes de salir del campo e incluya medios en copias o transferencias completas cuando deban moverse.

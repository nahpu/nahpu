Los datos asociados permiten vincular archivos no multimedia a un registro. Puede utilizarlos para adjuntar archivos como permisos, protocolos, registros de secuencias o documentos.

Seleccione `Link` o `File` en `Data type`. Añada un nombre, una descripción y una fecha, y proporcione una URL estable o una ruta de archivo. En la aplicación de escritorio, puede copiar un archivo adjunto al directorio de NAHPU o enlazarlo a su ruta existente en el disco.

Use `Media` para imágenes, audio y video. El formulario de medios registra metadatos de los archivos multimedia y ofrece una galería para ver los registros.

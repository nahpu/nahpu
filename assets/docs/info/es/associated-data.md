Los datos asociados conectan un registro con enlaces y archivos no multimedia de apoyo, como referencias de accesión, conjuntos de datos, permisos, protocolos, registros de secuencias o documentos.

Elija el tipo de dato que describa la relación, agregue un nombre, una descripción y una fecha, y proporcione un URI estable o un archivo gestionado. Use Media para imágenes, audio y video, de modo que los metadatos audiovisuales se registren de forma consistente. Verifique cada enlace o archivo después de agregarlo y no adjunte material sensible salvo que su acceso y difusión estén autorizados.

## Contexto de Darwin Core

Los datos asociados no tienen una clase propia en Darwin Core. Las exportaciones tabulares asignan estos registros a términos de Dublin Core: el nombre a `dcterms:title`, el tipo de dato a `dcterms:type`, la descripción a `dcterms:description`, la fecha a `dcterms:created` y el URI a `dcterms:identifier`.

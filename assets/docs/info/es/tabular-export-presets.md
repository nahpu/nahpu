---
title: "Presets de exportación tabular"
sidebar:
  order: 0
---

Un preset de exportación tabular guarda tipo de registro, alcance taxonómico, selección y orden de campos, estilo de encabezado y comportamiento de valores repetidos. El formato, nombre y destino se eligen al ejecutar la exportación.

Use asignaciones estándar solo cuando el campo NAHPU tenga el mismo significado que el término de destino. Encabezados Darwin Core como `dwc:scientificName` o `dwc:samplingProtocol` no deben asignarse solo porque las etiquetas parezcan similares. Pruebe con registros representativos, incluidos valores ausentes y repetidos, y transfiera user configs cuando los colaboradores necesiten la misma definición.

title: "Actividad del evento"
sidebar:
  order: 0
---

Elija la actividad principal que mejor describa el evento de recolección. Registre en las notas las actividades secundarias, circunstancias inusuales o el trabajo representado por `Other`.

Activity es una categorización del proyecto para filtrar y elaborar informes de forma coherente. El procedimiento real de muestreo corresponde a los registros de esfuerzo y puede exportarse como `dwc:samplingProtocol`. No use la etiqueta de actividad en lugar de equipo, duración, cantidad u otros detalles del esfuerzo.

---
title: "Identidad del sitio"
sidebar:
  order: 0
---

Un sitio es el registro reutilizable de lugar de NAHPU y corresponde a la información de ubicación que usan los eventos de recolecta. Asigne a cada sitio un Site ID estable y único en el proyecto, y use una misma convención de nombres en todos los dispositivos colaboradores.

Registre a la persona responsable y el tipo de sitio cuando sean útiles. Use `Duplicate site` para copiar la información descriptiva dejando vacíos el nuevo Site ID y las coordenadas. Use `Copy from project` solo cuando un sitio existente en otro proyecto contenga información que deba reutilizarse; verifique todos los valores copiados antes de comenzar la recolecta.

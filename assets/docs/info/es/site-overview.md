Un sitio es el registro de lugar reutilizable de NAHPU.

Registre el `Site ID`, el `Site Leader` y el `Site Type` cuando sea útil. `Site Leader` es la persona que registra los datos de un sitio determinado.

Para crear un sitio a partir de otro existente, abra el menú `Site actions` (tres puntos) en la parte superior derecha de la pantalla del sitio y seleccione `Duplicate site` o `Copy from project ...`. Use `Duplicate site` para copiar la información descriptiva y dejar vacíos el nuevo `Site ID` y las coordenadas. Use `Copy from project ...` solo cuando un sitio de otro proyecto describa un lugar que deba reutilizarse. Verifique cada valor copiado antes de comenzar la recolecta.

Un sitio se vincula a un espécimen mediante un evento de recolecta. Debe crear un evento antes de vincular un sitio a un espécimen.

---
title: "Identidad del sitio"
sidebar:
  order: 0
---

Un sitio es el registro reutilizable de lugar en NAHPU y corresponde a la información de ubicación usada por los eventos de recolección. Asigne a cada sitio un Site ID estable y único en el proyecto y use una convención común en todos los dispositivos colaboradores.

Registre la persona responsable y el tipo de sitio cuando sean útiles. Use `Duplicate site` para copiar información descriptiva dejando vacíos el Site ID nuevo y las coordenadas. Use `Copy from project` solo cuando un sitio de otro proyecto contenga información que deba reutilizarse; verifique todos los valores copiados antes de recolectar.

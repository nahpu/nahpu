title: "Resumen del evento"
sidebar:
  order: 0
---

Un evento de recolecta registra un esfuerzo de muestreo definido en un sitio y en un momento. Corresponde a un `dwc:Event` de Darwin Core, o evento de muestreo, y puede vincularse con varios registros de especímenes.

NAHPU deriva el Event ID del Site ID y de la fecha de inicio; agregue un sufijo solo cuando otro evento tendría el mismo identificador. Cree un evento separado cuando el sitio, el período, el protocolo de muestreo, el esfuerzo o el equipo participante cambien de forma significativa.

Duplicar un evento reutiliza la configuración aplicable, pero adelanta las fechas y deja vacíos los datos meteorológicos. Revise cada valor copiado antes de usarlo.

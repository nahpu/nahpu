`Media` menyimpan gambar, audio, dan video yang terkait dengan suatu catatan. Berkas media dapat dikaitkan secara langsung dan terpisah dengan lokasi, kegiatan, atau spesimen. Gunakan `Add` untuk mengimpor berkas atau, jika perangkat mendukungnya, mengambil foto, merekam video, atau merekam audio.

Setelah berkas media ditambahkan, buka menu titik tiga dan pilih `Edit` untuk mengubah nama berkas, keterangan, tag, dan fotografer. NAHPU menentukan kategori media (audio, video, atau gambar) dari format berkas. Tanggal pengambilan serta rincian kamera dan lensa dibaca dari metadata berkas jika tersedia.

Gunakan `Export` pada item media untuk menyimpan satu berkas, dengan pilihan untuk mengonversinya ke JPEG, PNG, atau WebP dan mengubah ukurannya. Untuk menyimpan beberapa berkas sekaligus, buka galeri media, aktifkan pilihan, lalu pilih `Export`.

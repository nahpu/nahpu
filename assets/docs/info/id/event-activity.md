Pilih aktivitas utama yang menggambarkan kegiatan pengumpulan. Secara default, NAHPU menyediakan tiga aktivitas: Collecting, Recording, dan Observing. Anda dapat menyesuaikan pilihan untuk aktivitas tersebut (misal, menambahkan Trapping atau Netting) di `Settings` > `Events` > `Primary Activities`.

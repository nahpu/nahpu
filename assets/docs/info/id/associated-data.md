Data terkait menghubungkan sebuah catatan dengan berkas yang bersifat non-media. Anda dapat menggunakannya untuk melampirkan berkas tambahan seperti berkas perizinan, protokol, catatan sekuens, atau dokumen lainnya.

Pilih `Tautan` atau `Berkas` pada `Jenis data`. Tambahkan nama, deskripsi, dan tanggal, lalu sediakan URL yang stabil atau jalur file. Di aplikasi desktop, Anda dapat menyalin berkas lampiran ke direktori NAHPU atau menautkannya ke jalur yang sudah ada di disk.

Gunakan `Media` untuk gambar, audio, dan video. Formulir media mencatat metadata audiovisual dan menyediakan galeri untuk melihat catatan.

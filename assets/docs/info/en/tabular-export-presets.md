A tabular export preset saves a repeatable definition: the record type, the specimen taxon group, the selected fields and their order, the generated header format, and how repeated values are written. The output format, file name, and destination are chosen during export.

`Generated header format` determines how headers are named: `table::fieldName`, `fieldName`, Darwin Core, or the NAHPU namespace. Repeated values can be written in one column with a separator or spread across indexed columns such as `field_1` and `field_2`.

Except for changes to the name and description, preset customizations are saved as you make them.

NAHPU provides default presets to help you get started. Use `Edit fields` to customize them.

---
title: "Sampling effort"
sidebar:
  order: 0
---

Effort records describe how sampling was performed. Add each method separately and record relevant equipment brand or model, number of units, size or dimensions, duration, and notes.

Use the same units and controlled method names throughout the project. The method can support `dwc:samplingProtocol`; the quantity, duration, area, or other magnitude of sampling supports `dwc:samplingEffort`. State enough context for another person to understand and compare the effort without inferring missing details.

Effort records describe methods, counts, and other relevant details. Duplicating an event copies its effort records. NAHPU provides a limited set of default methods. To customize the options, go to `Settings` > `Events` > `Collection Methods`.

`Add` each method separately and record the number of units, the brand and model of the equipment, its size or dimensions, and notes. Include the units in the size values (e.g., "10 cm × 10 cm × 10 cm").

Use the same units and controlled method names throughout the project so efforts can be compared.

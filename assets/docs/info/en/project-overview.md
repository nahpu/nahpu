A project groups the sites, collecting events, specimens, personnel, taxa, narratives, and supporting files for one body of work. Use `Edit` to update project information. Set the project time zone to describe the recorded local times. Changing it does not convert existing date and time values. The time zone is also stored in case third-party applications need it.

The project UUID identifies the project across devices. `Export info` and `Show QR` share its identity and metadata, without records or media.

For a daily field backup, use `Export project`. ZIP and TAR.GZ include available media; the light JSON.GZ format contains records without media.

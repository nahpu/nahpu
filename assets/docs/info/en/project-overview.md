A project groups the sites, collecting events, specimens, personnel, taxa, narratives, and supporting files for one body of field- or specimen-based work. Use `Edit` at the bottom of the Project Overview panel to update project information.

Set the project time zone to describe the recorded local times. Changing the project time zone does not convert existing date and time values. The time zone is stored with the project and included in exports, so third-party applications can interpret the recorded times. Time zones are listed relative to Coordinated Universal Time (UTC), the primary time standard used worldwide, from UTC−12:00 to UTC+14:00, each with a Continent/City name. For example, United States Eastern Daylight Time appears as `(UTC-04:00) America/New_York`.

The project UUID is a unique identifier for the project across devices. To share the project with collaborators, select the QR code in the Project Overview panel to enlarge or save it, or select `Export info` at the bottom of the panel. Collaborators scan the QR code when creating a new project. Both options share the project UUID and metadata, without records or media.

For a daily field backup, go to the menu and select `Export project`. ZIP and TAR.GZ include all records and the available attached media; the light JSON.GZ format contains records without media.

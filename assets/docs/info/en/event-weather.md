Environmental data records conditions for this event. In `Settings` > `Events`, choose which built-in fields to display in the panel. Hiding a field does not delete its stored values or exclude them from exports.

Record measurements in the displayed units: temperature in °C, humidity in percent, and rainfall in millimeters. Cloud cover uses codes 0–8 for eighths of the sky covered, or 9 for an obscured sky. Leave unmeasured values empty; zero is a measurement.

A duplicated event starts with blank environmental data.

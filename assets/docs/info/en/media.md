sidebar:
  order: 0
---

Media stores supported images, audio, and video associated with a project record. Use `Add` to import a file or, where available, take a photo or video or record audio.

Record a clear title, media kind, creator or photographer, date, and notes when known. These describe the media resource and can support Audiovisual Core `ac:Media` metadata; they do not replace specimen, event, or location data. Confirm that the managed file opens before leaving the field and include media in backups or full project transfers when it must move to another device.

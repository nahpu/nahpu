`Media` stores the images, audio, and video associated with a record. Media files can be attached directly and independently to a site, an event, or a specimen. Use `Add` to import a file or, if the device supports it, to take a photo, record a video, or record audio.

Once a media file is added, select its three-dot menu and choose `Edit` to change the file name, caption, tag, and photographer. NAHPU sets the media category (audio, video, or image) from the file format. Capture date, camera, and lens details are read from the file’s metadata when available.

Use `Export` on a media item to save a single file, with options to convert it to JPEG, PNG, or WebP and to resize it. To save several files at once, open the media gallery, turn on selection, and select `Export`.

`Media` stores the images, audio, and video associated with a record. Use `Add` to import a file or, where the device supports it, to take a photo, record a video, or record audio.

`Edit` the file name, caption, tag, and photographer. The category follows the file type. Capture date, camera, and lens details are read from the file’s metadata when available.

Use `Export` on a media item to save one file, with options to convert it to JPEG, PNG, or WebP and to resize it. To save several files at once, open the media gallery, turn on selection, and select `Export`.

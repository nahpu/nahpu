Geography describes the administrative hierarchy of the site, from country down to the precise locality. Remarks is an open field for context that does not fit any of the named fields. You can configure which geographic fields appear in `Settings` > `Sites` > `Geography fields`.

Localities are stored once and shared between sites across projects, so reusing a saved locality avoids creating duplicate sites. Once you have created a new site, use the `Find existing locality` search field at the top of the Geography panel to save time and keep locality names consistent.

---
title: "Site geography"
sidebar:
  order: 0
---

Geography describes the site’s location using fields that map to Darwin Core location terms: country, state/province, county, municipality, locality, and location remarks.

Enter values according to the responsible institution’s geographic conventions. `Locality` should describe the specific named place below municipality level; remarks can preserve directions or context that does not belong in a standard geographic field. Keep verbatim evidence when normalizing place names so later curators can understand the original source.

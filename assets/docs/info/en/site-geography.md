Geography describes the administrative hierarchy of the site, from country down to the precise locality, with remarks for context that does not fit a named field. Configure which geographic fields appear in `Settings` > `Sites` > `Geography fields`.

Localities are stored once and shared between sites across projects, so reusing a saved locality avoids creating a near-duplicate record. Use `Find existing locality` to save time and ensure consistent locality names.

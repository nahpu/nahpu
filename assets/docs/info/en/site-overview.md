A site is NAHPU’s reusable place record. Collecting events refer to a site for their location, so give every site a stable, project-unique Site ID and use one naming convention across collaborating devices.

Record the responsible person, site type, and the start and end dates for work at this site. A project can contain many sites, each with its own dates. Collecting events still record each visit. Use `Duplicate site` to copy descriptive information while leaving the new Site ID and coordinates empty. Use `Copy from project ...` only when a site in another project describes a place that should be reused. Verify every copied value before collection begins.

A site describes a place, while an event describes work at that place. Reuse the site for repeated visits and create the appropriate events for each sampling period.

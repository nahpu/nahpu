---
title: "Site identity"
sidebar:
  order: 0
---

A site is NAHPU’s reusable place record and corresponds to location information used by collecting events. Give every site a stable, project-unique Site ID and use one naming convention across collaborating devices.

Record the responsible person and site type when useful. Use `Duplicate site` to copy descriptive information while leaving the new Site ID and coordinates empty. Use `Copy from project` only when an existing site in another project represents information that should be reused; verify all copied values before collection begins.

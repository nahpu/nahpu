A site is NAHPU’s reusable place record.

Record the `Site ID`, `Site Leader`, and `Site Type` when useful. The `Site Leader` is the person who records the data for a given site.

To create a new site from an existing one, open the `Site actions` menu (three dots) at the top right of the site screen and select `Duplicate site` or `Copy from project ...`. Use `Duplicate site` to copy descriptive information while leaving the new `Site ID` and coordinates empty. Use `Copy from project ...` only when a site in another project describes a place that should be reused. Verify every copied value before collection begins.

A site is linked to a specimen through a collecting event. You must create an event before linking a site to a specimen.

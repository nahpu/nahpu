A site is NAHPU’s reusable place record. Collecting events refer to a site for their location, so give every site a stable, project-unique Site ID and use one naming convention across collaborating devices.

Record the responsible person and site type when useful. Use `Duplicate site` to copy descriptive information while leaving the new Site ID and coordinates empty. Use `Copy from project ...` only when a site in another project describes a place that should be reused; verify every copied value before collection begins.

## Darwin Core context

The Site ID identifies the location in exports and is written to `dwc:locationID`; site remarks become `dwc:locationRemarks`.

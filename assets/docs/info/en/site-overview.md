A site is NAHPU’s reusable place record.

Record the `Site Leader` and site type when useful. The `Site Leader` identifies who records the data and is in charge of the site.

Use `Duplicate site` to copy descriptive information while leaving the new `Site ID` and coordinates empty. Use `Copy from project ...` only when a site in another project describes a place that should be reused. Verify every copied value before collection begins.

A site is linked to a specimen through a collecting event. Create an event before linking a site to a specimen.

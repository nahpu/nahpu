Associated data connects a record to non-media files. You can use it to attach files such as permits, protocols, sequence records, or documents.

Choose `Link` or `File` in `Data type`. `Add` a name, description, and date, and provide a stable URL or a file path. On desktop, you can copy an attached file to the NAHPU directory or link to its existing path on disk.

Use `Media` for images, audio, and video. The media form records audiovisual metadata and provides a gallery for viewing the records.

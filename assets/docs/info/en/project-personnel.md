`Personnel` include all people who participate in the project. A person is stored once in the database and can be assigned to multiple projects. A person must be added to a project before being added to a site, event, or specimen record. Removing a person from this panel removes the project assignment; permanent deletion of a person from the database is managed in `Settings` > `Personnel`.

NAHPU roles:

- **Cataloger:** records specimen data and may supply initials and a personal field number for Field IDs.
- **Determiner only:** identifies specimens but does not catalog or prepare them.
- **Preparator only:** prepares specimens but does not catalog them (e.g., has no personal field number and does not record specimen data).
- **None:** participates in fieldwork without a specimen-care role.

To assign an identifier to a specimen, NAHPU supports either initials + an incremental number or a project-defined prefix + an incremental number + an optional suffix. NAHPU calls the former a `Field ID` and the latter a `Project ID`. Configure this in `Settings` > `Specimens` > `Field ID`.

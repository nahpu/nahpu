A symbiont record documents an organism living on or in the host specimen, whether parasitic, mutualistic, commensal, or phoretic. Use the interaction type for how it relates to the host, and the category for where it lives.

Keep the host association and symbiont identifiers consistent with the sample labels. A blank symbiont section does not establish that symbionts were absent. Use the symbiont examined and detected fields in the specimen attributes when that distinction matters.

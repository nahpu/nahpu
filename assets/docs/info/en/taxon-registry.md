The registry contains the taxonomic names available to a given project. Specimen records point to a registered taxon for their identification. Every taxon must be added to the registry before it can be assigned to a specimen.

`Add` taxa manually or import .xlsx, .csv, or .tsv files. To add a taxon manually, first select the narrowest rank you will record in `Taxon rank` at the top of the form (e.g., species). The form then shows the name fields laid out hierarchically down to that rank.

Imports accept class, order, family, genus, species, and subspecies records. Each row requires the classification fields from class through to its selected rank. Review every detected column mapping before import.

The panel counts the distinct orders, families, and full species names held in the registry. A total taxa count appears when the registry also holds names above or below species rank. These are registered taxon counts, not counts from specimen records. See Record statistics for the latter.

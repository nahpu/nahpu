A collecting event describes a defined period of sampling at a specified site. A single event is one session of active specimen collection at one site over a specific period of time, and one site can have several events. For example, you may collect at a site on one day when it is raining and return to the same site two weeks later when it is sunny. The different weather may influence your results or require different collecting methods, so it is useful to record those visits as separate events. Alternatively, you may treat one site per season as a single collecting event. Use events to divide the collecting at a site by time in the way that suits your work.

`Specimens` linked to the same collecting event share the same site information and sampling context. When creating an event, choose start and end dates/times that describe the actual collecting effort, including work that spans midnight.

NAHPU builds the `Event ID` from the `Site ID` and start date. For example, an event at site `CAMP-01` that starts on 20 October 2026 is named `CAMP-01-2026-10-20`. To distinguish events from the same site on the same date, go to `Event Identity` and select the pencil icon to the right of the `Event ID` to add a suffix (e.g., `1` and `2`, or `backyard` and `porch`).

Create a separate event when the collecting period, protocol, effort, or team changes. For consistency, one person should create the event and share it with other devices used to catalog specimens from that event. Use the event QR code to share the event and add it on other devices.

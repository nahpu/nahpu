A collecting event describes sampling at a site over a defined period. `Specimens` linked to it share the site and sampling context. Choose start and end dates and times that describe the actual effort, including work that spans midnight.

NAHPU builds the `Event ID` from the `Site ID` and start date. `Add` a suffix to distinguish events at the same site on the same date.

Create a separate event when the period, protocol, effort, or team changes. For consistency, one person should create the event and share it with other devices used to catalog specimens from that event. Use the event QR code to share the event and add it on other devices.

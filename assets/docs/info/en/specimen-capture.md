Capture information connects the specimen to the collecting event that supplies its site, sampling context, date range, and field team.

Record the capture date, time, method, collector, and coordinate specific to this specimen.

Select a `Site ID` first, then select the `Event ID` for the collection. Changing the event clears the method, collector, and coordinate in this panel so values from the previous event are not silently retained; capture date and time are kept. Always review every field after changing the event.

`Coordinate extent` describes how far the specimen could have been from the recorded position. Use it when a trap line, transect, or search area is wider than the coordinate itself.

By default, if a site has only one coordinate, NAHPU selects that coordinate automatically.

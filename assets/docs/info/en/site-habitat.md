Site attributes record the habitat observed at the site. NAHPU provides default values for `Habitat Type`. You can customize the available `Habitat Type` options in `Settings` > `Sites` > `Habitat Types`.

Use the habitat description to note evidence that helps interpret the collecting environment, such as dominant vegetation, substrate, canopy or ground cover, water conditions, disturbance, and land use. Record collecting methods, sampling equipment, and effort in the collecting event, not the site.

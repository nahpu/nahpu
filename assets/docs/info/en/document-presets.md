Document settings separate reusable templates from print layouts. A template defines one label, tag, sheet, or document block. A print layout defines page size, margins, template blocks, copies, ordering, and pagination.

Create separate layouts for distinct workflows and use `Save as` before experimenting with a known-good preset. Preview with representative records, long text, missing values, and both sides of duplex templates. A PDF document export is for printing or presentation; it is not a structured data export or a restorable backup. Transfer matching templates and layouts together through user configurations.

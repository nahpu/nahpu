Document presets consist of reusable templates and print layouts. A preset defines page margins, orientation, padding, and template block settings. Template blocks organize the templates and define their order and layout on a page. Within each template block, you select a template.

A template defines a layout linked to data fields. You can create your own layouts for purposes such as tissue labels, specimen tags, or PDFs of all records. Open the template editor directly or click the edit button (pencil icon).

When designing a template, you can use bundled fonts or import your own fonts. `Fonts` are managed in `Documents` > `Fonts`.
